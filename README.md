# Jade Wok — Modern Chinese Restaurant & Dim Sum HTML Template

**Version 1.0.0** · Static HTML5 / CSS3 / Vanilla JavaScript

Jade Wok is a premium, responsive restaurant website template for a contemporary Chinese dining brand. It combines an editorial jade-and-ivory visual system with complete restaurant pages, accessible interactions, sample content, SEO foundations and a documentation site ready for commercial customization.

## Highlights

- 15 complete standalone HTML pages, including homepage, menu, dish details, reservations, private dining, gallery, chefs, locations, contact, FAQ, journal, article and 404 pages.
- Responsive layout tuned for desktop, tablet and small mobile screens.
- Vanilla JavaScript interactions: mobile navigation, sticky header, menu and journal filters, gallery lightbox, FAQ accordions, testimonial carousel, demo form validation, cookie notice and back-to-top control.
- Original SVG brand mark, favicon and a reusable jade / ivory / gold design system.
- SEO-ready metadata, Open Graph tags and Restaurant JSON-LD on every page.
- Extensive documentation in `docs/`, including installation, customization, content, images, forms, JavaScript, accessibility and credits.

## Installation

No build process or npm installation is required. Open `index.html` directly for a quick preview, or serve the folder from a simple static server such as `python3 -m http.server 8080`. Upload the complete folder to any static host or shared hosting account.

## Documentation

Start with [`docs/index.html`](docs/index.html) or [`docs/documentation.md`](docs/documentation.md). The documentation explicitly identifies fictional demo content, explains replacement of remote image URLs, describes every page and records the newly added sections such as the culinary journey, private dining package system, chef timeline, location cards and expanded journal.

## Important demo notes

The restaurant name, address, telephone number, email address, timeline, awards, testimonials, prices, menu items and article content are fictional demonstration content. Reservation, contact, newsletter and private dining forms validate in the browser and show simulated success states; they do not send data. Map panels are documented placeholders and do not contain API keys.
