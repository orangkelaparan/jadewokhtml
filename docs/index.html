01 · Overview

Built to be edited.

Jade Wok is a complete 15-page restaurant template using only HTML5, CSS3 and vanilla JavaScript. It is designed to open directly in a browser or deploy to any static host without npm, a database or server-side rendering.

02 · Installation

Three steps to preview.

  1. Open the project folder.
  2. Double-click index.html, or run python3 -m http.server 8080.
  3. Upload the folder contents to shared hosting or a static host.

Read installation.md for cPanel and FTP notes.

03 · Customization

Make it yours.

Edit CSS variables in assets/css/style.css, replace remote image URLs, update the inline logo and revise the fictional contact details. The main guide includes page-by-page instructions and form integration notes.
